# ur_coach

An AI research assistant that answers your questions from recent papers and articles, with numbered sources and a credibility score for each one. Follow a topic and it keeps itself up to date.

Works in Arabic and English with no translation layer.

## How it works

1. **Scout** searches Semantic Scholar and Tavily, with extra queries generated by an LLM.
2. **Curator** removes duplicates, filters by topic relevance, and stores chunks in FAISS and SQLite.
3. **Critic** scores each chunk for credibility and relevance (0 to 5).
4. **Coach** retrieves the best chunks, researches automatically when coverage is weak, and answers in the language of the question with numbered citations.
5. **Scheduler** refreshes followed topics and saves a digest.

Embeddings use `intfloat/multilingual-e5-small`. LLM calls go through one wrapper with automatic fallback (Gemini, then Groq).

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Fill in `.env`:

- Provider keys: `GEMINI_API_KEY`, `TAVILY_API_KEY`, `SEM_API_KEY`, and optionally `GROQ_API_KEY`.
- `API_KEYS`: comma-separated secrets. Generate each with `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`.
- `UI_API_KEY`: one of the values in `API_KEYS`, used by the web page through the server.
- `INVITE_CODES`: comma-separated codes, one per person.

Run with a single worker (rate limits and the ingestion lock live in memory):

```bash
uvicorn coach_service.main:app
```

Open `http://localhost:8000/` and enter an invite code.

## API

All routes except `/`, `/health` and `/login` need an `X-API-Key` header (the web page gets it from the server after login).

| Route | Purpose |
|---|---|
| `POST /ask` | Answer a question with sources |
| `POST /research` | Start a background research job (returns `job_id`) |
| `GET /jobs/{id}` | Job status |
| `POST /subscribe` | Follow a topic |
| `DELETE /subscribe/{topic}` | Unfollow a topic |
| `GET /digest/{topic}` | Latest digest |
| `GET /health` | Health check |

## Notes

- Changing the embedder means deleting `metadata.db` and `faiss_index.bin` and re-ingesting.
- Scores are a guide, not ground truth. Always check the sources.
